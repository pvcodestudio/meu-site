# Don Marco Barbearia — demonstração de layout

Página visual derivada do arquivo corrigido `Don-Marco-Barbearia-Etapa-1-Codigo-Documentacao.rar` fornecido pelo autor do portfólio. Substitui a demonstração montada a partir do ZIP anterior.

Abra `/demonstracoes/don-marco/` pelo servidor do projeto. O acesso também aparece no trabalho Don Marco Barbearia, na seção Projetos do portfólio.

O HTML apresenta a página inicial “Seu corte, do jeito que você gosta”, o catálogo de serviços, a galeria e as informações da barbearia. Essas áreas ficam disponíveis por links internos, sem depender de abas em JavaScript. A tela de agendamento também aparece como exemplo visual preenchido, com todos os controles desativados.

Não há scripts de aplicativo, formulários de conta, coleta de dados, simulação de confirmação ou conexão com agenda. Os links externos de contato e mapa estão desativados. Textos, valores, datas e avaliações são ilustrativos.

Os estilos, imagens e fontes vieram do RAR correto. `assets/css/demonstracao.css` acrescenta a faixa de demonstração, o link de retorno e a disposição das áreas em uma página navegável. As demais folhas CSS preservam os componentes visuais originais.

As fontes DM Sans e Playfair Display vieram em `assets/fonts/` no arquivo recebido. Suas licenças estão em `LICENCA-dmsans.txt` e `LICENCA-playfairdisplay.txt`.

Scripts, arquivos de configuração, chaves, bancos locais e áreas de gestão do aplicativo original não fazem parte desta demonstração. Não é necessário instalar ou iniciar o aplicativo da barbearia.
