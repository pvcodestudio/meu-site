# Martins Advocacia — demonstração visual

Apresentação estática do projeto `K:/Projetos pedro/landingpage-advocacia`, fornecido pelo autor do portfólio. Os arquivos de origem foram preservados.

Abra `/demonstracoes/advocacia/` pelo portfólio. O terceiro card substitui o projeto MarketUp, mantendo a estrutura da seção Projetos.

O layout apresenta a identidade visual, as áreas de atuação e o escritório. A navegação usa âncoras e um menu nativo em telas pequenas. Não há scripts de aplicativo, formulários, confirmações de agendamento, links de contato ativos ou envio de dados. Os dados de endereço, registro profissional e contato foram substituídos por indicações ilustrativas.

Os estilos e fotografias vieram do projeto fornecido. Cormorant Garamond e Plus Jakarta Sans são servidas localmente, com as licenças OFL em `assets/fonts/`. `assets/css/demonstracao.css` acrescenta o aviso, o retorno ao portfólio e a navegação sem JavaScript.
